# Aurora | Biblioteca Digital

Aurora é um protótipo de biblioteca Digital onde você explora um acervo de livros, busca por título ou autor e abre os detalhes de cada obra, com sinopse, autor, ano, número de páginas e disponibilidade.

**Acesse o site:** https://inspiring-vacherin-45697f.netlify.app/

## Sobre o projeto

Ao criar uma conta e entrar, você pode favoritar livros e pegar livros emprestados. Tudo fica reunido no seu perfil, em duas abas: uma com os livros favoritos e outra com os emprestados, que mostra a data da retirada e até quando devolver.

O visual é em tons de verde, creme e laranja, pensado para quem acredita no poder da leitura.

## Como usar

Abra o site, explore o acervo e clique em um livro para ver os detalhes. Para favoritar ou pegar um livro emprestado, crie sua conta ou entre pelo botão "Entrar" no topo da página. Depois, clique no seu nome para abrir o perfil.

## Observações

Este é um projeto de estudo. A disponibilidade dos livros é simulada, e a recuperação de senha ainda não está disponível.
